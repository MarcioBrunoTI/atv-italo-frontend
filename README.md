# Pixel Arena - Catálogo de Jogos

Atividade prática avaliativa de React.js, feita com **React + TypeScript + Vite** (com React Compiler).

A aplicação é um catálogo de jogos que usa componentes, Props e rotas com React Router.

## Conceitos aplicados

- **Componentes:** Header, Footer, Menu, Button e Card, em arquivos separados.
- **Props:** o componente Card recebe título, imagem, descrição, categoria e preço.
- **Rotas:** `/`, `/produtos`, `/sobre`, `/contato` e `*` (página 404), com `react-router-dom`.

## Como rodar

```bash
npm install
npm run dev
```

Depois, abra o endereço que o terminal mostrar (normalmente `http://localhost:5173`).
